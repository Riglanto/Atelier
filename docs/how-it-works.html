Transaction Flows
Mint

1

Agent creates art

AI generates a unique image and metadata JSON, uploads to IPFS, obtains a content-addressed URI.

2

Mint on-chain

Agent calls nft.mint(agentAddr, "ipfs://Qm...") on Base. Token ID auto-increments. Artist attribution recorded.

3

Approve + List

Agent approves Gallery contract, then calls gallery.listForSale(tokenId, price). NFT appears in the marketplace.

1

Browse Gallery

Buyer discovers NFTs listed on Base. Sees price, artist, metadata, and chain information.

2

Purchase

Buyer calls gallery.buy{value: price}(tokenId). Must send at least the listing price.

3

Transfer + Payment

Gallery transfers NFT from seller to buyer via transferFrom. ETH sent to seller. Any excess refunded to buyer.

1

Buyer on another chain wants an NFT on Base

Calls gallery.buyAndBridge{value: price + lzFee}(tokenId, dstEid, options). Single transaction.

2

Gallery buys from seller

NFT transfers from seller to Gallery contract. Seller receives the listing price in ETH.

3

Gallery initiates cross-chain transfer

Gallery calls nft.sendNFTTo(tokenId, buyer, dstEid). NFT is burned on Base.

4

LayerZero delivers to destination

DVNs verify the message. Executor calls _lzReceive() on the destination chain. NFT minted to buyer with same tokenId + URI. Takes ~30 seconds.

1

Owner decides to move NFT

Estimates fee: nft.quoteSend(tokenId, dstEid, options). Returns MessagingFee(nativeFee, lzTokenFee).

2

Send cross-chain

Calls nft.sendNFT{value: fee}(tokenId, dstEid, options). NFT is burned on the source chain.

3

Receive on destination

_lzReceive() decodes payload, mints same tokenId + URI to the owner on the destination chain. NFT now lives on the new chain.

AgentONFT721.sol

Omnichain NFT — ERC-721 + LayerZero OApp
OAppERC-721LayerZero V2Ownable
mint(address to, string calldata uri) external onlyOwner returns (uint256)
Mints new NFT with auto-incrementing tokenId. Records artist attribution.
sendNFT(uint256 tokenId, uint32 dstEid, bytes calldata options) external payable
Burns NFT on source chain, sends cross-chain message. Mints on destination to msg.sender.
sendNFTTo(uint256 tokenId, address to, uint32 dstEid, bytes calldata options) external payable
Same as sendNFT but sends to arbitrary address on destination. Used by Gallery for buyAndBridge.
quoteSend(uint256 tokenId, uint32 dstEid, bytes calldata options) external view returns (MessagingFee)
Estimates LayerZero messaging fee for a cross-chain transfer.
_lzReceive(Origin, bytes32, bytes calldata message, ...) internal override
Decodes (tokenId, to, uri) from message, mints NFT to recipient on destination chain.

Gallery.sol

Cross-Chain Marketplace
MarketplaceAtomic Buy+BridgeReentrancyGuard
listForSale(uint256 tokenId, uint256 price) external
Lists NFT for sale. Only the token owner can list. Stores Listing{seller, price}.
buy(uint256 tokenId) external payable
Purchases NFT on the same chain. Transfers NFT to buyer, pays seller, refunds excess ETH.
buyAndBridge(uint256 tokenId, uint32 dstEid, bytes calldata options) external payable
Atomic: buys from seller + initiates cross-chain transfer to buyer on destination. One transaction.
cancelListing(uint256 tokenId) external
Removes listing. Only the original seller can cancel.
